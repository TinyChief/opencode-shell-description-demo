# Demo screenshots for opencode shell-tool description proposal

Companion assets for the GitHub issue requesting an optional `description`
field on the `shell` tool in anomalyco/opencode (v1 parity, Claude Code
parity).

- `openchamber-before.png` — OpenChamber row today: raw command only.
- `openchamber-after.png` — OpenChamber row with the comment on the first line
  (plugin workaround; with a native `description` field the client would
  render it as a dedicated line).
- `tui-before.png` — opencode TUI before (raw command).
- `tui-after.png` — opencode TUI after (command with a leading comment line).

See the opencode issue for the full proposal.
